# Hyprland Config

Personal Hyprland configuration written in Lua (Hyprland 0.55+), migrated from the legacy `.conf`/hyprlang format. Structured for modularity and maintainability.

## Structure

```
hyprland/
├── hyprland.lua          # Entry point — loads all modules in order
├── noctalia.conf         # Color theme (auto-managed by Noctalia, do not edit)
├── monitors.conf         # Monitor layout (auto-generated by nwg-displays)
├── workspaces.conf       # Workspace rules (auto-generated by nwg-displays)
├── config/
│   ├── general.lua       # Input, layout, env vars, scrolling
│   ├── decoration.lua    # Blur, shadow, opacity, window rules
│   ├── animation.lua     # Bezier curves and animation definitions
│   ├── startup.lua       # exec-once autostart entries
│   ├── plugins.lua       # Plugin settings (hyprbars, hyprexpo — commented)
│   ├── binds.lua         # All keybindings
│   ├── monitors.conf     # Auto-generated by nwg-displays
│   └── workspaces.conf   # Auto-generated by nwg-displays
├── dms/
│   ├── layout.conf       # Auto-generated by DMS
│   └── windowrules.conf  # Auto-generated by DMS
└── scripts/
    └── wallpaper-selector.sh
```

Files marked **auto-generated** are managed by external tools and must not be hand-edited.

## Module Overview

### `hyprland.lua`
Entry point. Loads modules in this order: `general` → `decoration` → `animation` → `startup` → `plugins` → `binds`. Also sources `noctalia.conf` for the color theme.

### `config/general.lua`
- Cursor theme: `Bibata-Modern-Classic` at size 24
- Keyboard layout: `us`
- Window gaps: 8px inner, 12px outer
- Layout engine: `dwindle`
- Border resize enabled; border size 0 (borderless)
- Scrolling layout direction: right

### `config/decoration.lua`
- Window rounding: 10px
- Global opacity: 90% active and inactive
- Blur: 8px size, 4 passes, xray enabled, vibrancy 0.1696
- Shadow: range 20, render power 3
- Window rules: browsers, gaming apps, productivity apps are forced fully opaque (1.0); scrcpy always floats

### `config/animation.lua`
- Custom bezier curve `overshoot` (0.34, 1.4 → 0.64, 1) for a slight springy feel
- Windows and workspaces use `overshoot` with `slide` style
- Fade, border, borderangle use the `default` curve

### `config/startup.lua`
Autostart entries run once on login:
- `noctalia -d` — Noctalia shell daemon (v5)
- `hyprpm reload` — reload Hyprland plugin manager
- `wl-paste` (text + image) piped to `cliphist` for clipboard history

### `config/plugins.lua`
Plugin settings for `hyprbars` and `hyprexpo` are fully written but commented out. Plugin loading is handled by NixOS/hyprpm — uncomment settings here once the Lua plugin API stabilises.

### `config/binds.lua`
See [Keybindings](#keybindings) below.

## Keybindings

Shell IPC commands use Noctalia v5 (`noctalia msg <command>`).

```lua
local shell_cmds = {
    launcher   = "noctalia msg panel-toggle launcher",
    wallpaper  = "noctalia msg panel-toggle wallpaper",
    ...
}
```

## Notes

- Requires **Hyprland 0.55+** (Lua config API — hyprlang `.conf` syntax is no longer used for hand-written files)
- `noctalia.conf` is sourced for colors but is not loaded via `require()` since it is a `.conf` file, not Lua
- Plugin loading (`hyprbars`, `hyprexpo`) is managed by NixOS flake inputs, not by this config
- Monitor and workspace files inside `config/` are written by `nwg-displays` and will be overwritten on any display reconfiguration — do not edit them manually
- The `noctalia.kill` command pattern (`pkill -f 'qs.*noctalia-shell'`) assumes the standard `noctalia-qs` runtime binary; verify with `ps aux | grep noctalia` if kill fails
